## What it was

Aurelia explored a more personal way of discovering jewelry. Instead of starting with a conventional catalog and many filters, the concept began with signals about the person receiving or wearing the piece, then framed discovery around AI-assisted recommendations.

The project was a product and interaction prototype rather than a production commerce platform. Its main purpose was to explore how AI-assisted personalization could sit behind a premium consumer interface without making the experience feel technical.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Historical notes

The prototype included English/Spanish localization, responsive layouts, subtle motion and a browser-local waitlist experiment. A production version would have required a real backend, authenticated state and persistent recommendation services.

This repository is retained as historical project work only.
